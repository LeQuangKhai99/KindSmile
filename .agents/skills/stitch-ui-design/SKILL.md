# Stitch UI/UX Design Skill Instructions

## Overview
This skill provides Google Stitch AI design principles and guidelines for crafting world-class, modern, high-end web interfaces.

## Key Design Principles

### 1. Visual Hierarchy & Luxury Palette
- **Primary Accent**: Kind Smile Vibrant Orange (`#F9571B`, gradient to `#FF6B2B`).
- **Deep Contrast**: Dark Slate Charcoal (`#0F172A` / `#1E293B`) for high-contrast headers, dark hero cards, and footers.
- **Background Tints**: Soft Warm Cream (`#FFF8F5`) and Glassy Translucent Overlays (`rgba(255, 255, 255, 0.85)`).
- **Gradients**: Linear & radial glow gradients (`linear-gradient(135deg, #F9571B 0%, #FF7A45 100%)`).

### 2. Micro-Interactions & Elevation
- **Card Hover Effects**: Smooth vertical translation (`translateY(-8px)`), multi-layered soft drop shadows (`box-shadow: 0 20px 40px -15px rgba(249, 87, 27, 0.25)`).
- **Glassmorphism**: Backdrop filter blurs (`backdrop-filter: blur(12px)`), subtle semi-transparent borders (`border: 1px solid rgba(255, 255, 255, 0.2)`).
- **Floating Badges & Quick Action Chips**: Interactive service pills with glow indicators on hover.

### 3. Typography & Spacing
- **Font**: Inter with heavy contrast weights (800/900 for headlines, 600 for labels, 400 for copy).
- **Section Spacing**: Ample breathing room (`padding: 6rem 0`), clean rounded containers (`border-radius: 24px`).
